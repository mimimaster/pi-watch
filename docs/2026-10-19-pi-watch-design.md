# pi-watch 设计说明

日期：2026-10-19
状态：已实现（独立扩展）
关联产品：pi / piwin（安装为扩展，不改 piwin 核心）

## 1. 目标

让 pi / piwin 能「看视频」：不是原生视频模态，而是把视频预加工成模型已支持的输入——**带时间戳的字幕文本 + 抽帧图片**。

成功标准：

1. 本地 mp4：`/watch` 产出帧图 + 字幕或本机 Whisper 转写，模型能回答「某秒画面上有什么」。
2. 公开网页 / YouTube 链接：在已安装 `yt-dlp` 时可下载并同样分析。
3. 缺 `ffmpeg`、或无 Whisper 时：错误可读；「仅有帧、无转写」仍可跑通。
4. `--start` / `--end` 能明显减少帧数。
5. 有基础单测覆盖抽帧数量规则、字幕优先于 Whisper、`doctor` 探测（不依赖真实下载 YouTube）。

非目标：

- 改 piwin / pi 核心代码。
- 云端 Whisper / Gemini 整段看视频。
- 实时流式分析。
- 把 ffmpeg / Whisper 模型打进安装包。

## 2. 架构

```
用户 (/watch 或拖入视频路径)
        │
        ▼
┌─────────────────┐
│ resolve-source  │  本地校验 / yt-dlp 下载
└────────┬────────┘
         ▼
┌─────────────────┐
│ extract-frames  │  ffprobe + ffmpeg → JPEG
└────────┬────────┘
         ▼
┌─────────────────┐
│ transcribe      │  字幕 → 否则本机 Whisper
└────────┬────────┘
         ▼
┌─────────────────┐
│ inject          │  字幕时间轴 + 帧图 → 当前会话
└─────────────────┘
```

默认限制：约 100 帧、约 768px 宽、约 20 分钟（可用 `--start` / `--end` 开窗）。
